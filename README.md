## 🎮 Sorteador de Looks - Pixel RPG
Este é um aplicativo em Kotlin com Jetpack Compose que sorteia combinações de roupas e acessórios em estilo pixel art retrô, inspirado em jogos de RPG.
O usuário pode gerar combinações aleatórias de óculos, camisas, casacos, calças e tênis, criando visuais divertidos e únicos.

## ✨ Funcionalidades
🎲 Sorteio de diferentes peças de roupas e acessórios.
🕹️ Interface retrô no estilo RPG.
👕 Combinações dinâmicas entre óculos, camisas, casacos, calças e tênis.

## 🚀 Tecnologias Utilizadas
- Kotlin
- Jetpack Compose
- Android Studio
